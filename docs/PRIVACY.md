# Приватність

- Track Catcher записує лише звук, який грає сам телефон (AudioPlaybackCapture). Мікрофон не пишеться, дзвінки — теж.
- «Доступ до сповіщень» використовується лише для того, щоб бачити, що грає плеєр: назву, виконавця, альбом, обкладинку. Тексти сповіщень не читаються й нікуди не передаються.
- Записи зберігаються лише на телефоні (`Music/Track Catcher/`, папки альбомів — всередині). Історія — у пам'яті застосунку.
- Інтернет — лише для оновлень з Google Диска автора (з v0.1.15, рішення faric 14.10): застосунок читає маленький файл версії й, якщо треба, APK. Записи, історія й назви пісень нікуди не передаються; немає сервера, реклами, аналітики.
- Резервне копіювання Android вимкнено (`allowBackup=false`).
- Записи — для особистого користування. Деякі застосунки забороняють запис свого звуку — тоді Track Catcher записує тишу й позначає запис «невдало».
