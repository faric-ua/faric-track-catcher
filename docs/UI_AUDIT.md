# Аудит інтерфейсу

## Метод

1. **Код** — `scripts/audit_ui.py` (CI «Checks»): правила UI-01…UI-10 з `docs/UI_STYLE_CONTRACT.md`.
2. **Емулятор** — workflow «UI screens» (`scripts/ci/ui-screens.sh`): Pixel 6, Android 14, демо-дані (лише debug-збірка). Знімки:
   книжкова й альбомна; шрифт 1.0 і 1.3; вікно «Видалити?» до й після повороту; падіння застосунку → помилка CI.
   Знімки лежать у гілці `diag/ui-screens-out` (у `main` не мержиться).
3. **Телефон** (Samsung A26) — остаточно; матриця нижче.
