# Телефон: перший запуск Track Catcher

## Один раз — поставити меню

У Termux вставити один рядок (це єдина команда; далі — лише пункти меню):

```
git clone https://github.com/faric-ua/faric-track-catcher ~/faric-track-catcher && bash ~/faric-track-catcher/menu.sh
```

Потім у меню: **9** — ярлик «Track Catcher» для Termux:Widget (далі меню відкривається одним дотиком).

## Один раз — ключ підпису

Меню → **7**. Скрипт:
1. створює ключ `~/.android/track-catcher.jks` (пароль — випадковий, у `~/.android/track-catcher-signing.properties`, доступ лише Termux);
2. передає його в секрети GitHub (`TC_KEYSTORE_B64`, `TC_STORE_PASSWORD`, `TC_KEY_ALIAS`, `TC_KEY_PASSWORD`, `TC_CERT_SHA256`) через `gh`;
3. запускає збірку релізу.

Потрібно: Java 17 (`keytool`) і `gh`, що увійшов у GitHub, — обидва вже є після налаштувань Renault/Dorama.
Меню → **8** — резервна копія ключа в `Documents/Track Catcher/key-backup/` (нікому не пересилати).

## Встановити / оновити

Меню → **2**: бере останній реліз з GitHub, перевіряє SHA-256, кладе в `Documents/Track Catcher/apk/vX.Y.Z/` і відкриває встановлення → «Встановити» / «Оновити».

## Дозволи в застосунку (картка «Що дозволити»)

| Пункт | Навіщо | Де |
|---|---|---|
| Запис звуку | Android називає це «Мікрофон», але пишеться лише звук телефона | вікно Android |
| Назви пісень | «Доступ до сповіщень» — назва, виконавець, обкладинка зі шторки | Налаштування → Доступ до сповіщень |
| Повідомлення | видно запис у шторці й кнопку «Стоп» | вікно Android |
| Робота у фоні | Samsung не приспить запис з вимкненим екраном | вікно Android |

**Обмежене налаштування.** Android 13+ блокує «Доступ до сповіщень» для застосунків, встановлених з файлу. Якщо перемикач сірий:
Налаштування → Застосунки → Track Catcher → ⋮ (угорі праворуч) → «Дозволити обмежені налаштування» → назад і увімкнути доступ.

## Резерв — збірка на телефоні

Меню → **11** (як Dorama DEV 17). Перша збірка качає бібліотеки (AGP, Kotlin, jump3r) з Maven — потрібен інтернет, але не GitHub. Далі меню → **12** збирає **без інтернету** з кешу Gradle. Код береться з папки на телефоні (оновлюється пунктом 1, коли GitHub доступний). Потрібні ті самі речі, що для Dorama: Java 17, `~/android-sdk`, ARM64 `aapt2` (у `~/.gradle/gradle.properties`), `~/gradle/gradle-8.13`, плюс ключ з пункту 7. Лог — `Documents/Track Catcher/logs/`.
