# Інтерфейс Track Catcher — контракт

Код: `ui/Palette.kt` (усі кольори), `ui/Ui.kt` (усі кнопки, картки, вибір, статуси). Новий елемент — лише з цих блоків.
Автоперевірка: `python3 scripts/audit_ui.py` (у CI, правила UI-01…UI-10).

## Образ

Касетна дека вночі: темний фон, бурштиновий акцент (як підсвітка шкали), червоний — лише запис. Індикатор рівня з сегментів L/R, як на деці.

| Роль | Колір |
|---|---|
| Фон | `#0E1116` |
| Картка | `#171C23`, рамка `#333D4B`, радіус 16 dp |
| Текст / другорядний | `#F2F5F8` / `#A3AEBB` |
| Акцент (головна дія, рівень) | `#FFB15A` |
| Запис | `#FF5A4E` |
| Вибране / «повний» | рамка `#62D296` 2 dp на `#16271E` |
| «Неповний» | `#A99FFF` |
| «Невдало» / небезпечна дія | `#FF7A88` |
| Попередження | `#F0B968` |

Шрифт — системний sans; заголовки — medium; числа — табличні цифри (`tnum`).

## Правила

| № | Правило |
|---|---|
| UI-01 | Без стандартних сірих діалогів і кнопок Android — лише `Overlay` і `Ui.button`. Системні вікна (дозвіл на запис, налаштування) — дозволені. |
| UI-02 | Кольори лише з `Palette.kt`. |
| UI-03 | Вибране — зелена рамка, без галочок ✓. |
| UI-04 | Зона дотику ≥ 48 dp (велика кнопка запису — 56 dp). |
| UI-05 | Кожна вкладка має книжковий і альбомний варіант. Дві колонки — коли ширина ≥ 600 dp. Нічний екран — один, по центру, для обох. |
| UI-06 | Орієнтацію не блокуємо. |
| UI-07 | Довгі українські підписи переносяться (до 3 рядків), без фіксованої висоти; шрифт не зменшуємо. **Виняток — вкладки:** підпис в один рядок, що не влазить — «…» (власник, 13.10: «щоб влазило в один строчечку»). |
| UI-08 | Відкрите вікно переживає поворот (ключ вікна зберігається в стані). |
| UI-09 | Усі підписи — українською. |
| UI-10 | «Скасувати / Закрити» — остання кнопка (праворуч). |
| UI-11 | Видалення — лише після підтвердження; запис в історії лишається з поміткою. |
| UI-12 | Статус — словом і кольором (пігулка), не лише кольором. |

## Розкладки

| Екран | Книжкова | Альбомна (≥ 600 dp) |
|---|---|---|
| Каркас | шапка «Track Catcher» + вкладки знизу | вкладки в лівій смузі |
| Запис | одна колонка: стан → зараз грає → кнопка → формат → дозволи → сесія | ліворуч стан/пісня/кнопка, праворуч дозволи/сесія |
| Історія | пошук, фільтри, список; подробиці — у вікні | список ліворуч, подробиці праворуч |
| Налаштування | одна колонка карток | дві колонки карток |

Під час запису на інших вкладках у шапці видно червоний значок «● 12:34 · 3» — дотик повертає на «Запис».
