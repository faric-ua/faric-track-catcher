## Цикл роботи

1. Код + тести у своїй копії → гілка `feat/…` / `fix/…` / `docs/…` → PR у `main`.
2. Зелений CI (`Checks`, `Android`) → мерж (squash) самому.
3. Нова версія для телефона = підняти `versionName` (X.Y.Z) **і** `versionCode` в `android/app/build.gradle.kts`. Мерж у `main` сам публікує реліз `vX.Y.Z` (лише з ключем підпису, лише якщо такого тегу ще нема).
4. Дати faric шлях: `Track Catcher → 2` (встановити реліз) і що перевірити.
5. Результат («пас / не пас», скрін) — записати в `STATUS.md` (таблиця + журнал) і `docs/PROJECT_LEDGER.md`.

## Докази (не плутати)

- Перевірка коду ≠ юніт-тест ≠ зелений CI ≠ **phone PASS**. Телефон — джерело правди.
- Три окремі стани: версія в репо · опублікований реліз · встановлено на телефоні.
- Не ставити «пас» за власника. Не давати тести для збірки, яку ще не можна встановити.

## Стиль — Track Catcher ведучий (faric 16.10 16:31)

- «Track Catcher був перший — він ведучий за стилем; конвертер дивиться на нього». Спільний стиль з **Audio Converter**
  (`faric-ua/faric-audio-converter`, приватний): `ui/Palette.kt` (кольори), `ui/LineIcon.kt` + `core/SvgPath.kt` (значки),
  `docs/UI_STYLE_CONTRACT.md` (правила). Конвертер копіює їх своїм скриптом `tools/dev/sync_style.py` (лише назва пакета;
  свої кольори — окремим блоком у кінці його `Palette.kt`). Сюди конвертер нічого не пише.
- Тому ці три файли — самодостатні: без посилань на решту Track Catcher (крім `Ui.dp` у `iconText`).
- **Спільна плитка плеєра** (faric 17.10 18:40): `ui/PlayerView.kt` + `TransportButton.kt` + `ActionTile.kt` теж копіюються в конвертер.
  Програвач (`InAppPlayer`) — у кожного свій. Змінив плитку — підняти `PlayerView.TILE_VERSION` і рядок у «Журнал стилю»;
  конвертер звіряє цю версію тестом і підтягує, якщо відстає.
- **Спільна панель «Про файл»** (faric 17.10 23:39): `ui/FileInfoPanel.kt` + `core/FileTags.kt` + `ui/FlowLayout.kt` + `core/FlowRows.kt`
  теж копіюються в конвертер (M4A / Opus конвертер читає сам і передає в ту саму панель). Змінив — `FileInfoPanel.PANEL_VERSION` + «Журнал стилю».
- Змінив стиль (колір, значок, розмір значків, кнопки) — рядок у `docs/UI_STYLE_CONTRACT.md` → «Журнал стилю»
  (дата, що змінилось): так чат конвертера бачить, що підтягнути. Значок, потрібний конвертеру, теж додається тут.

## Технічне

- Gradle 8.13 **без wrapper** (CI — setup-gradle; телефон — `~/gradle/gradle-8.13`). AGP 8.13.2, Kotlin 2.3.21, SDK 36, minSdk 29.
- Тести: `python3 -m unittest discover -s tests`; Kotlin-юніт-тести лише в CI (у середовищі Claude немає Android SDK і Maven).
- Логи Actions недоступні — усе важливе CI виводить анотаціями: `gh api repos/faric-ua/faric-track-catcher/check-runs/<id>/annotations`.
- Збірка для телефона — `assembleRelease` без мініфікації (не debuggable → MP3 кодується швидко).
- Ключ підпису: створює телефон (меню 7) → секрети `TC_*` у GitHub. Телефон зберігає `~/.android/track-catcher.jks` + `track-catcher-signing.properties`.
