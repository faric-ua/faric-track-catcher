# Track Catcher

Android-застосунок: записує звук, який грає телефон (будь-який плеєр), ріже його на окремі пісні й зберігає кожну під її назвою зі шторки — у WAV, MP3 або в обох форматах. Історія показує, що записано: повністю, частково, невдало чи пропущено.

- Власник: faric (`faric-ua`). Працює з телефона через Termux-меню.
