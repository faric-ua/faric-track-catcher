# Track Catcher

Android-застосунок: записує звук, який грає телефон (будь-який плеєр), ріже його на окремі пісні за назвою зі шторки й зберігає кожну — у WAV, MP3 або в обох форматах. Історія показує, що записано: повністю, частково, невдало чи пропущено.

- Власник: faric (`faric-ua`), працює з телефона через Termux-меню — `docs/PHONE_SETUP.md`.
- Правила для асистента — `CLAUDE.md` (звідки взялися — `docs/RULES.md`). Стан — `STATUS.md`. Задачі — `TODO.md`. Журнал — `docs/PROJECT_LEDGER.md`.
- Інтерфейс — `docs/UI_STYLE_CONTRACT.md`, аудит — `docs/UI_AUDIT.md`. Приватність — `docs/PRIVACY.md`. Сторонній код — `THIRD_PARTY.md`.

Android 10+. Kotlin, без Compose. MP3 — jump3r (LAME, LGPL).
